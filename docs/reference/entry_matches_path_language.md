# Whether an entry matches a language / path selector

Matches when `language` appears in the entry's path
[`step_path_languages()`](https://replicate-anything.github.io/replicateEverything/reference/step_path_languages.md),
or when the dispatch engine matches (classic bilingual groups).

## Usage

``` r
entry_matches_path_language(entry, language, paper_meta = NULL)
```
