# Resolve the selected path entry within a grouped row

Resolve the selected path entry within a grouped row

## Usage

``` r
group_entry_for_path_selector(row, selector)
```

## Arguments

- row:

  Grouped replication data.frame row (with `entries`).

- selector:

  Language / path selector (e.g. `"r"`, `"mathematica"`).

## Value

Matching entry list, or `NULL`.
