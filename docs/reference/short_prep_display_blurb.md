# Collapse and optionally truncate a yaml blurb for Display captions

Collapse and optionally truncate a yaml blurb for Display captions

## Usage

``` r
short_prep_display_blurb(text, max_chars = 140L)
```

## Arguments

- text:

  Character scalar.

- max_chars:

  Maximum length before ellipsis (default 140).

## Value

Single-line character scalar.
