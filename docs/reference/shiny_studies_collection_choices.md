# Collection filter choices from a Shiny Studies cache (baked UI, with fallback)

Collection filter choices from a Shiny Studies cache (baked UI, with
fallback)

## Usage

``` r
shiny_studies_collection_choices(cache)
```

## Arguments

- cache:

  Result of
  [`load_shiny_studies_cache()`](https://replicate-anything.github.io/replicateEverything/reference/load_shiny_studies_cache.md).

## Value

Named character vector.
