# Build the one-line partial-replication notice shown on study select

Build the one-line partial-replication notice shown on study select

## Usage

``` r
format_partial_replication_message(
  engines = character(0),
  incomplete_n = 0L,
  audit_failed = 0L,
  audit_timed_out = 0L,
  data_unavailable = character(0)
)
```
